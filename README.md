# News Detection Using NLP

## Project Overview
News Detection Using Natural Language Processing (NLP)
is a project that analyzes news text using text-processing
techniques to identify suspicious wording.

## Objectives
- Analyze user-provided news text.
- Apply basic text-processing techniques.
- Demonstrate a simple news analysis web application.
- Learn about NLP and machine learning.

## Technologies Used
- Python
- Flask
- Natural Language Processing (NLP)
- Scikit-learn
- Pandas
- NumPy
- NLTK

## Current Features
- News text input form.
- Basic keyword-based analysis.
- Result displayed on a web page.

## How to Run
1. Install Python 3.
2. Install the dependencies:

   pip install -r requirements.txt

3. Start the application:

   python app.py

4. Open http://127.0.0.1:5000 in your browser.

## Limitation
The current version uses simple keyword matching.
It does not prove whether a news story is true or false.
A trained machine-learning model and a suitable dataset
are needed for actual fake-news classification.
